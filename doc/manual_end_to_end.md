# Owner end-to-end guide (`lico 0.2.3`)

Version: 1.6.0

This guide is for the account owner administering Lico on Linux. Lico never reads a provider's login files and never stores a provider secret in plaintext; application-owned credentials live only in the OS keyring (`lico cred`, failing closed when the store is locked or missing), and each account owns a private directory (`0700`) that the provider itself populates when you sign in. A live provider session may incur provider usage charges.

State lives in `$XDG_STATE_HOME/lico` (or `~/.local/state/lico`), and the local owner-only socket defaults to `$XDG_RUNTIME_DIR/lico/host.sock`. Everything ships in one self-contained executable (`lico`): `lico gui` opens the administrator window, `lico host` runs the background session host, `lico --version` prints the build identity, and `lico licenses` prints third-party notices.

## Administrator window (`lico gui`)

1. **Start, maximized launch, and host continuity**: `lico gui` opens maximized on the active monitor by default (`lico gui --windowed` opts out to standard `1280x820` windowed sizing) and starts `lico host` automatically if none is running (and replaces an older host build cleanly while reconnecting existing sessions). Closing the window or pressing **Esc** on an empty input line detaches the view without stopping running sessions.
2. **Accounts, SSH remote targets, and sign-in (`Ctrl+A`)**:
   - Press **A** to add a local or SSH remote account: **Tab** toggles provider (`codex` or `claude`), and **Up** / **Down** (or clicking the target row) chooses `local (this machine)` or any explicit host alias discovered from `~/.ssh/config` (`[ssh: <host>]`). SSH remote accounts run `claude auth login` / `codex login` directly on the remote host over `BatchMode=yes` SSH inside an isolated `0700` remote `$HOME/.local/state/lico/accounts/<id>/{home,<provider>}` so the remote host connects directly to its LLM API provider without copying tokens to the local machine.
   - Press `1..9` to open an account's actions: **S** signs in with the provider's own flow (**Ctrl+C** / **Ctrl+Shift+C** copies the URL, **Ctrl+O** opens it in the browser, **D** selects Codex device-code sign-in; any verification code typed or pasted into the input line is masked as `*`, sent once, and cleared immediately without logging).
   - **F** sets the default account for that provider; **R** renames the account label in place without touching credentials or account homes; **D** removes the account while keeping its sessions unbound; **E** removes the account and ends its sessions (both ask for a second press after naming bound sessions).
3. **New sessions (`Ctrl+N`)**:
   - Choose provider (`codex` or `claude`), local or `[ssh: <host>]` account (or create one inline), permission mode (`auto` skips routine tool prompts; `default` asks on each gated action), optional model/effort, working folder (`Folder`, supporting `~` / `~/...` on SSH remote hosts and reading `CLAUDE.md` without trusting repo-local `.claude/settings.json`, `.mcp.json`, or `.codex/config.toml`), and optional local git worktree branch (`Worktree`, creating an isolated branch checkout for local repositories).
4. **Two-pane workbench, horizontal session tabs (`+G` Global general sessions), left `[ Directories ]` | `[ Past ]` sidebar, bottom telemetry bar, and daily session control**:
   - Open sessions live in a horizontal **Session Tab Bar** across the top of the right chat pane (`+` opens a folder session, `+G` or **Ctrl+Shift+N** opens a folder-less `Global` general session with a `G·` badge for quick ad-hoc questions, `×` closes or deletes a tab, and `<`/`>` or mouse wheel scrolls overflow tabs), while the **Left Sidebar** (**Ctrl+B** collapses/expands) provides two tabs: `[ Directories ]` (local and `Host: <ssh> v` directory tree, gold `★` active `cwd` highlight + `-> active` jump-back pill, teal `★ Global (general)` scope, instant filter, `.dot` toggle, pagination, and wide inline UTF-8 file preview where **Esc** returns straight to chat) and `[ Past ]` (full `offset`/`limit` paginated discovery across all past `claude` and `codex` conversations for the selected directory or `Global` scope with zero top-N truncation, plus 1-click resume or tab focus).
   - A color-coded per-session **Bottom Telemetry Bar** directly above the status hint displays `Model (Effort) | Tok: in / out | 5h & Wk remaining % (+ reset) | CWD / Global` (clicking the path syncs the left sidebar to the session's active directory).
   - A clickable **Toolbar** directly below the menu bar exposes `+ New`, `Accounts`, `Files`, `Close`, `Rename`, `Mode` (`auto` <-> `default`), `Group`, `Send -> Session` (with live peer count when multiple sessions run), conditional `Copy` (when transcript lines or prompt text are selected), and `Find`. Typing `/exit` or `/quit` in the prompt box (or clicking tab `×`) dismisses the session tab locally (`tab_closed: true`, purging blank 0-turn tabs and keeping conversation-bearing tabs resumable from `[ Past ]`) without sending `/exit` to the LLM or polluting `auto_title`. Pressing **Ctrl+Tab** / **Ctrl+Shift+Tab** / **Alt+1..9** or clicking any top session tab closes an open panel cleanly and switches straight to that session. Unnamed sessions derive an `auto_title` from their first non-slash prompt or workspace folder, and active (`running`) sessions sort ahead of idle/closed ones in reverse chronological order of activity (`last_active_at`).
   - Internal host control markers (`[session started]`, `[turn started]`, `[turn completed]`, `[provider reconnected]`, `[provider disconnected]`, `[session closed]`, `[exit 0]`) stay in durable `.seg` logs while remaining hidden by default in `lico gui` (`View > Internal events: hidden|shown`, **Ctrl+Shift+E**); user prompts (`>> ...`), incoming inter-session messages (`>> [from session ...]` teal peer banner), agent responses, and per-invocation bordered command/tool execution cards (`$ ...`, slate-teal stdout, coral-amber `[exit != 0]` / `[tool error]`, `[tool] ...`, `[patch] ...`) render with distinct colors and subtle user-turn row tinting. Both `claude` (`get_usage` + `rate_limit_event`) and `codex` populate live `5h` and `Wk` remaining percentages and reset countdowns in the bottom telemetry bar, session headers (`7d XX% left`, with `LOW`/`CRITICAL` indicators below `20%`/`5%`), and `Accounts`.
   - **F2** (or double-clicking a row) renames a session; **Ctrl+Shift+B** (`Session > Rebind account...`) moves a disconnected session to another account of the same provider; **Ctrl+Shift+M** (`Session > Permission mode: ...` or toolbar `Mode`) toggles `auto` <-> `default` live (restarting an idle Claude session cleanly with `--resume`); **Ctrl+Shift+W** closes a session (keeping its history and worktree choice for **Ctrl+R** or **Enter** to resume); **Ctrl+Delete** deletes a session (two-step warning if a Lico-managed git worktree has uncommitted files; a user-chosen folder is never deleted).
   - **Y** / **N** (or the **Allow** / **Deny** buttons) answer pending approvals; for Lico's own agent tool cards, **S** allows for the remainder of the session and **V** opens the full request text.
   - Inside the multi-line prompt editor, click or drag with the mouse or hold **Shift** with movement keys (**Shift+Arrows**, **Shift+Home**, **Shift+End**, **Ctrl+Shift+Left/Right**) to select prompt text; **Ctrl+C** copies and **Ctrl+X** cuts an active prompt selection when no transcript lines are selected (keeping **Ctrl+A** dedicated to `Accounts`, with physical-key fallback so all `Ctrl+` and `Alt+` shortcuts work identically under Hangul `한/영` or non-Latin IME layouts); **Ctrl+Z** and **Ctrl+Y** / **Ctrl+Shift+Z** perform bounded per-session undo and redo; resizing the window reflows wrapped lines while keeping the scroll position anchored.
   - **Ctrl+C** / **Ctrl+Insert** (or **Ctrl+Shift+C**, or toolbar `Copy`) copies selected transcript lines without mouse-drag selection ever overwriting X11 `CLIPBOARD` or `PRIMARY`; **Ctrl+V** pastes text (up to 64 KiB, multi-line with **Shift+Enter**) or attaches a PNG image chip in a Claude session (**Esc** drops the chip and immediately reclaims heap memory); **Shift+Insert** or middle-click pastes the primary selection; **Ctrl+Shift+P** captures the screen into the Claude input box.
   - **Ctrl+Shift+S** (or toolbar `Send -> Session`) sends the draft or selected lines to another `claude` or `codex` session (inline up to 4 KiB, file handoff above 4 KiB without truncation), and both local `claude` and `codex` sessions expose Lico's loopback MCP inter-session tools (`sessions`, `history`, `send`, `read_handoff`) with human approval cards; `Session > Hand over conversation...` hands over a full transcript.
   - `Session > Virtual display: start/stop` manages a session's private `Xvfb` display for computer use; **Ctrl+Alt+Esc** (or the red banner button) immediately revokes time-bounded (15-minute max) real-screen control.
5. **Working-directory file viewer (local and SSH remote), hidden-file toggle, workspace grouping, text size, search, notifications, and memory (`View` menu)**:
   - **Ctrl+E** (or toolbar `Files` / `View > Working directory files`) opens the strictly on-demand working-directory file viewer in the selected session's or remembered folder with zero background `inotify` watchers, and closing/reopening `lico gui` restores the previous local working directory and workspace view (`settings.json` `last_cwd`, `last_view`, `last_session`). Entries starting with `.` are hidden by default (`Hidden: off`) and toggle via toolbar `Hidden: off/on`, `View > Hidden files (.dotfiles)`, **Ctrl+H**, or **.**; toolbar `Host: local v` / `Host: <alias> v` (or **H**) opens a combo-box dropdown listing `local (this machine)` and `~/.ssh/config` hosts without blocking the window, loading remote directories asynchronously (`Esc` cancels in-flight connections; offline/removed hosts show a non-blocking `unreachable` view). Press **F5** (or toolbar `Refresh`) to reload directory entries explicitly; navigate large directories (`<= 10,000` entries) and multi-page text previews via toolbar `< Prev` / `Next >`, **Page Up** / **Page Down**, **[** / **]**, or the mouse wheel (`Page X / Y`); click `+ New here` (or press **N**) to open `New session` pre-populated in the browsed local or SSH directory; and click or press **Enter** on any file or safe symlink (symlink directories navigate into their target directory, and symlink files preview or open their resolved regular-file target while refusing symlinks into Lico's private state roots) to open UTF-8 text-family files directly in-window (`<= 64 KiB` preview; **Esc** or **Backspace** steps back) while local `.html`, documents (`.pdf`, `.pptx`, `.docx`, `.xlsx`), images, media, archives, and binary files launch in the OS default application (`xdg-open`).
   - **Ctrl+Shift+G** switches the session list between `Group by: account` and `Group by: workspace` (rolling git worktree sessions up under their parent repository); **Ctrl+=**, **Ctrl+-**, and **Ctrl+0** adjust the persistent window text size (`12..=20` px, default `14` px).
   - **Ctrl+F** searches within the open conversation; **Ctrl+Shift+F** searches across all sessions on demand with zero resident index overhead.
   - `View` toggles **Agent clipboard write** (default off; each write still asks) and **Desktop notifications** (`notify-send` when no window is attached; unread background turns show `•` and approvals show `!` in the list and window title).
   - Each session row shows private process-tree memory (`RssAnon + RssShmem` in M/G; amber from 1 GiB, red from 2 GiB), and the bottom-left summary reports total session, host, and window memory.

## Agent, script CLI, and loopback HTTP (`lico ...` and `127.0.0.1`)

- **Capabilities, status, settings, SSH hosts, and files**: `lico capabilities`, `lico status`, `lico resources`, `lico ssh hosts`, `lico ssh check HOST`, `lico settings [--clipboard-write on|off] [--notifications on|off] [--group-by account|workspace] [--font-size 12..20] [--show-events on|off] [--show-hidden on|off] [--last-cwd DIR] [--last-view start|files|session] [--last-session ID]`, `lico files [DIR] [--hidden|-a] [--ssh-host HOST]`, `lico files --read FILE [--ssh-host HOST]`, `lico host stop [--force]`.
- **Accounts**: `lico account create --provider codex|claude --label Work [--ssh-host HOST]`, `lico account rename ID LABEL`, `lico account list`, `lico account login ID [--device]`, `lico account auth ID`, `lico account default ID`, `lico account affected ID`, `lico account remove ID detach|end`.
- **Sessions, past history, and search**: `lico session list`, `lico session past [--cwd DIR | --global] [--ssh-host HOST] [--account ID] [--query TEXT] [--offset N] [--limit N]`, `lico session create --kind claude --account ID [--cwd DIR] [--worktree BRANCH] [--mode auto|default] [--resume ID]`, `lico session mode ID auto|default`, `lico session send ID TEXT|- [--from ID2 | --conversation --from ID2]`, `lico session watch ID`, `lico session close ID`, `lico session resume ID`, `lico session rebind ID ACCOUNT`, `lico session rename ID [NAME]`, `lico session delete ID`, `lico history ID BEFORE [LIMIT]`, `lico search QUERY [--session ID]`.
- **Loopback HTTP (`--http-port PORT|auto --http-token-file FILE`)**: Bound strictly to `127.0.0.1` with `Host`/`Origin` validation and `Bearer` credential checks; serves `GET /v1/capabilities`, `POST /v1` (every non-streaming v1 operation), `GET /v1/ssh/hosts`, `POST /v1/ssh/check`, `GET/POST /v1/accounts`, `POST /v1/accounts/<id>/rename`, `GET/POST /v1/sessions`, `GET /v1/sessions/past`, `GET /v1/sessions/<id>[/snapshot|/events|/history]`, `POST /v1/sessions/<id>[/input|/mode|/rebind]`, `GET /v1/search`, `GET /v1/files`, `GET /v1/files/read`, `GET/POST /v1/settings`, `POST /v1/approvals/<id>/response`, and `POST/DELETE /v1/views`.
- **Screen, clipboard, and displays**: `lico capture --screen|--window ID|--region x,y,w,h --out FILE`, `lico clipboard read ...`, `lico clipboard write ...`, `lico display [status|stop|run]`, `lico real-screen stop`.
