# Owner end-to-end guide (`lico 0.2.5`)

Version: 1.9.0

This guide is for the account owner administering Lico on Linux. Lico never reads a provider's login files and never stores a provider secret in plaintext; application-owned credentials live only in the OS keyring (`lico cred`, failing closed when the store is locked or missing), and each account owns a private directory (`0700`) that the provider itself populates when you sign in. A live provider session may incur provider usage charges.

State lives in `$XDG_STATE_HOME/lico` (or `~/.local/state/lico`), and the local owner-only socket defaults to `$XDG_RUNTIME_DIR/lico/host.sock`. Everything ships in one self-contained executable (`lico`): `lico gui` opens the administrator window, `lico host` runs the background session host, `lico --version` prints the build identity, and `lico licenses` prints third-party notices.

## Administrator window (`lico gui`)

1. **Start, maximized launch, and host continuity**: `lico gui` opens maximized on the active monitor by default (`lico gui --windowed` opts out to standard `1280x820` windowed sizing) and starts `lico host` automatically if none is running (and replaces an older host build cleanly while reconnecting existing sessions). Closing the window or pressing **Esc** on an empty input line detaches the view without stopping running sessions.
2. **Accounts, SSH remote targets, and sign-in (`Ctrl+A`)**:
   - Press **A** to add a local or SSH remote account: **Tab** toggles provider (`codex` or `claude`), and **Up** / **Down** (or clicking the target row) chooses `local (this machine)` or any explicit host alias discovered from `~/.ssh/config` (`[ssh: <host>]`). SSH remote accounts run `claude auth login` / `codex login` directly on the remote host over `BatchMode=yes` SSH inside an isolated `0700` remote `$HOME/.local/state/lico/accounts/<id>/{home,<provider>}` so the remote host connects directly to its LLM API provider without copying tokens to the local machine.
   - Press `1..9` to open an account's actions: **S** signs in with the provider's own flow (**Ctrl+C** / **Ctrl+Shift+C** copies the URL, **Ctrl+O** opens it in the browser, **D** selects Codex device-code sign-in; any verification code typed or pasted into the input line is masked as `*`, sent once, and cleared immediately without logging).
   - **F** sets the default account for that provider; **R** renames the account label in place without touching credentials or account homes; **D** removes the account while keeping its sessions unbound; **E** removes the account and ends its sessions (both ask for a second press after naming bound sessions).
3. **New sessions (`Ctrl+N`)**:
   - Choose provider (`codex` or `claude`), local or `[ssh: <host>]` account (or create one inline), permission mode (`auto` skips routine tool prompts; `default` asks on each gated action), optional model/effort, working folder (`Folder`, supporting `~` / `~/...` on SSH remote hosts and reading `CLAUDE.md` without trusting repo-local `.claude/settings.json`, `.mcp.json`, or `.codex/config.toml`), and optional local git worktree branch (`Worktree`, creating an isolated branch checkout for local repositories).
4. **Two-pane workbench, horizontal session & Call Room tabs (`+G` Global general sessions, `⇄ A·B`), left `[ Directories ]` | `[ Chats ]` | `[ Calls ]` sidebar, bottom telemetry bar, and daily session control**:
   - Open sessions and shared inter-session Call Rooms (`⇄ <Label A>·<Label B>`) live in a horizontal **Tab Bar** across the top of the right chat pane (`+` opens a folder session, `+G` or **Ctrl+Shift+N** opens a folder-less `Global` general session with a `G·` badge for quick ad-hoc questions, `×` closes or deletes a tab, and `<`/`>` or mouse wheel scrolls overflow tabs), while the **Left Sidebar** (**Ctrl+B** collapses/expands) provides three tabs: `[ Directories ]` (topped by a persistent `<` / `>` Back/Forward navigation toolbox across directories and pagination pages — **Alt+Left** / **Alt+Right** or mouse Back/Forward buttons — plus a `☆`/`★` bookmark toggle and `Marks (N) v` quick-jump popup persisted in `settings.json` across restarts; local and `Host: <ssh> v` directory tree, gold `★` active `cwd` highlight + `-> active` jump-back pill, teal `★ Global (general)` scope, instant filter, `.dot` toggle, pagination, and wide inline UTF-8 file preview where **Esc** returns straight to chat), `[ Chats ]` (full `offset`/`limit` paginated discovery across all past `claude` and `codex` conversations for the selected directory or `Global` scope with zero top-N truncation, plus 1-click resume or tab focus), and `[ Calls ]` (live `Calls (N)` count, `+ ⇄ <Peer> (<provider>)` quick-connect buttons from the active session, instant Call Room filtering, `[R/4]` / `[paused]` / `[idle]` status badges, 1-click Call Room tab opening, and `×` room close).
   - **`+ New chat`** (its own row above `[..]  parent directory` of the `[ Directories ]` tab, for the shown local or ssh directory; greyed with the reason when the host is unreachable or Global is shown) opens a small centered dialog: choose an account (Up/Down, or click; the default is marked), then `Resume` (default) or `New` (Left/Right, or click). `Resume` shows `Last Session : <provider> / <YYYY-MM-DD HH:MM> / <title> (<N> turns)` for that directory and account (`?` when the turn count is not known, as for ssh chats) and, on Enter, continues that chat (a tab that already holds it is shown again); with no earlier chat it says so and opens a new one. `New` starts a fresh auto-mode conversation. `Options...` (or `o`) opens the full new-session form for the same directory; Esc closes the dialog.
   - A color-coded per-session **Bottom Telemetry Bar** directly above the status hint displays `Model (Effort) | Tok: in / out | 5h & Wk remaining % (+ reset) | CWD / Global` (clicking the path syncs the left sidebar to the session's active directory).
   - A clickable **Toolbar** directly below the menu bar exposes `+ New`, `Accounts`, `Files`, `Close`, `Rename`, `Mode` (`auto` <-> `default`), `Group`, `Send -> Session` (with live peer count when multiple sessions run), conditional `Copy` (when transcript lines or prompt text are selected), and `Find`. Typing `/exit` or `/quit` in the prompt box (or clicking tab `×`) dismisses the session tab locally (`tab_closed: true`, purging blank 0-turn tabs and keeping conversation-bearing tabs resumable from `[ Chats ]`) without sending `/exit` to the LLM or polluting `auto_title`. Pressing **Ctrl+Tab** / **Ctrl+Shift+Tab** / **Alt+1..9** or clicking any top session tab closes an open panel cleanly and switches straight to that session. Unnamed sessions derive an `auto_title` from their first non-slash prompt or workspace folder, and active (`running`) sessions sort ahead of idle/closed ones in reverse chronological order of activity (`last_active_at`).
   - Internal host control markers (`[session started]`, `[turn started]`, `[turn completed]`, `[provider reconnected]`, `[provider disconnected]`, `[session closed]`, `[exit 0]`, and Call Room `[call done]` / line-clipped `[call done` suffixes) stay out of default user-visible conversation views (`View > Internal events: hidden|shown`, **Ctrl+Shift+E**); user prompts (`>> ...`), incoming inter-session messages and peer replies (`>> [peer reply from ...]` / `>> [from session ...]` mint-emerald peer card, deferred cleanly below an in-flight turn when a reply arrives while the receiver is busy), agent responses, and default-collapsed per-invocation command/tool/patch cards (`▸ $ ...`, `▸ [tool] ...`, `▸ [patch] ...` in an indigo-violet pill `#161426` with `#9B8AFB` rail, expanding on mouse click to `▾ ...` header `#1D1934` + `#121020` body with `#7C6CF6` rail, or coral-amber `[exit != 0]` / `[tool error]`, and collapsing back on header click while keeping drag-selection auto-copy intact) render with distinct colors and subtle user-turn row tinting. Both `claude` (`get_usage` + `rate_limit_event`) and `codex` populate live `5h` and `Wk` remaining percentages and reset countdowns in the bottom telemetry bar, session headers (`7d XX% left`, with `LOW`/`CRITICAL` indicators below `20%`/`5%`), and `Accounts`.
   - **F2** (or toolbar `Rename`, double-clicking a row, typing `/rename <Name>` / `/rename --clear` / bare `/rename` in any `claude` or `codex` session prompt, or asking the agent in natural language to call `mcp__lico__rename`) renames a session and syncs open Call Room titles immediately; **Ctrl+Shift+B** (`Session > Rebind account...`) moves a disconnected session to another account of the same provider; **Ctrl+Shift+M** (`Session > Permission mode: ...` or toolbar `Mode`) toggles `auto` <-> `default` live (restarting an idle Claude session cleanly with `--resume`); **Ctrl+Shift+W** closes a session (keeping its history and worktree choice for **Ctrl+R** or **Enter** to resume); **Ctrl+Delete** deletes a session (two-step warning if a Lico-managed git worktree has uncommitted files; a user-chosen folder is never deleted).
   - **Y** / **N** (or the **Allow** / **Deny** buttons in the centered **Approval Required** modal notification dialog, which also surfaces over the active view when an open background tab requests approval) answer pending approvals; selecting **Allow** (or **Y** / **Shift+S**) keeps `send` and `history` permissions active for the remainder of the session, while one-shot tools (`create`, `computer`, `capture`, `clipboard_read`, `clipboard_write`) ask on each call, and **V** (`Read Full (V)`) opens the full request text.
   - Inside the multi-line prompt editor, click or drag with the mouse or hold **Shift** with movement keys (**Shift+Arrows**, **Shift+Home**, **Shift+End**, **Ctrl+Shift+Left/Right**) to select prompt text; **Ctrl+C** copies and **Ctrl+X** cuts an active prompt selection when no transcript lines are selected (keeping **Ctrl+A** dedicated to `Accounts`, with physical-key fallback so all `Ctrl+` and `Alt+` shortcuts work identically under Hangul `한/영` or non-Latin IME layouts); **Ctrl+Z** and **Ctrl+Y** / **Ctrl+Shift+Z** perform bounded per-session undo and redo; resizing the window reflows wrapped lines while keeping the scroll position anchored.
   - Releasing a mouse drag selection in the conversation transcript, prompt editor, or any right-hand panel screen (`Send to session`, `Files` and inline preview, `Accounts`, `New session`, `Card`, `Keys`, `About`, `Start`) automatically copies the selected UTF-8 text onto X11 `CLIPBOARD` without touching `PRIMARY` (and **Ctrl+C** / **Ctrl+Insert**, **Ctrl+Shift+C**, or toolbar `Copy` also copies without closing an open panel, while stationary clicks `< 4 px` keep row activation intact); **Ctrl+V** pastes text (up to 64 KiB, multi-line with **Shift+Enter**) or attaches a PNG image chip in a Claude session (**Esc** drops the chip and immediately reclaims heap memory); **Shift+Insert** or middle-click pastes the primary selection; **Ctrl+Shift+P** captures the screen into the Claude input box.
   - Typing `@` in any session or Call Room prompt box opens an interactive **`@AgentName` autocomplete popup** (`ArrowUp` / `ArrowDown` selects, **Tab** or mouse click inserts `@Pri-Avatar `, `@"Quoted Name" `, or `@all `, **Esc** dismisses): sending a leading `@AgentName <message>` (or `@all <message>`) immediately opens/updates that pair's persistent **Call Room** (`0600` `registry/calls.json`, zero approval modal, session-long bidirectional authorization), attaches up to the calling session's last 8 turns (`<= 16 KiB`) plus the cumulative Call Room transcript inside a host-verified `[lico call ... | OWNER-AUTHORIZED]` envelope, and inserts a clickable `>> [⇄ call ...]` jump card in the calling session's transcript (stationary click on `[⇄ call ...]` or `[peer reply ... | call cXXXXXX ...]` opens the top-bar `⇄ A·B` Call Room tab directly, where `-> <Session>` jumps to either participant, typing in the prompt box sends a live human `call.say` intervention, and **Hang up** or **Ctrl+K** / **Ctrl+Shift+K** pauses auto-continuation immediately). **Ctrl+Shift+S** (or toolbar `Send -> Session`) sends the draft or selected lines to another `claude` or `codex` session (inline up to 4 KiB, file handoff above 4 KiB without truncation), and both local `claude` and `codex` sessions expose Lico's loopback MCP inter-session tools (`sessions`, `history`, `send`, `create`, `read_handoff`, `rename` — where `create` accepts `kind: "claude" | "codex"`, optional `prompt`, optional `name`, and optional `scope: "folder" | "global"` so either provider can ask to open a new `Claude` or `Codex` tab in `mode: "auto"` in `lico gui`, and `send.to` / `history.session` accept either hex session IDs or `@SessionName`, also routing unindented column-0 `@ExactSessionName <message>` assistant lines outside code blocks when `send` was not already called in that turn) with MCP `initialize` host-trust instructions and centered modal approval dialogs (`Allow` / `Deny`): once approved (`keep = true`), agent-to-agent collaboration logs into the pair's Call Room and runs up to **4 automatic round-trips per burst** (`MAX_CALL_ROUNDS = 4`, stopping early when a participant includes `[call done]` — stripped from visible prose — or replies without calling `send`, and refusing round 5 with `call_round_limit` until the next human turn); `Session > Hand over conversation...` hands over a full transcript.
   - `Session > Virtual display: start/stop` manages a session's private `Xvfb` display for computer use; **Ctrl+Alt+Esc** (or the red banner button) immediately revokes time-bounded (15-minute max) real-screen control.
5. **Working-directory file viewer (local and SSH remote), hidden-file toggle, workspace grouping, text size, search, notifications, and memory (`View` menu)**:
   - **Ctrl+E** (or toolbar `Files` / `View > Working directory files`) opens the strictly on-demand working-directory file viewer in the selected session's or remembered folder with zero background `inotify` watchers, and closing/reopening `lico gui` restores the previous local working directory and workspace view (`settings.json` `last_cwd`, `last_view`, `last_session`). Entries starting with `.` are hidden by default (`Hidden: off`) and toggle via toolbar `Hidden: off/on`, `View > Hidden files (.dotfiles)`, **Ctrl+H**, or **.**; toolbar `Host: local v` / `Host: <alias> v` (or **H**) opens a combo-box dropdown listing `local (this machine)` and `~/.ssh/config` hosts without blocking the window, loading remote directories asynchronously (`Esc` cancels in-flight connections; offline/removed hosts show a non-blocking `unreachable` view). Press **F5** (or toolbar `Refresh`) to reload directory entries explicitly; navigate large directories (`<= 10,000` entries) and multi-page text previews via toolbar `< Prev` / `Next >`, **Page Up** / **Page Down**, **[** / **]**, or the mouse wheel (`Page X / Y`); click `+ New here` (or press **N**) to open `New session` pre-populated in the browsed local or SSH directory; and click or press **Enter** on any file or safe symlink (symlink directories navigate into their target directory, and symlink files preview or open their resolved regular-file target while refusing symlinks into Lico's private state roots) to open UTF-8 text-family files directly in-window (`<= 64 KiB` preview; **Esc** or **Backspace** steps back) while local `.html`, documents (`.pdf`, `.pptx`, `.docx`, `.xlsx`), images, media, archives, and binary files launch in the OS default application (`xdg-open`).
   - **Ctrl+Shift+G** switches the session list between `Group by: account` and `Group by: workspace` (rolling git worktree sessions up under their parent repository); **Ctrl+=**, **Ctrl+-**, and **Ctrl+0** adjust the persistent window text size (`12..=20` px, default `14` px).
   - **Ctrl+F** searches within the open conversation; **Ctrl+Shift+F** searches across all sessions on demand with zero resident index overhead.
   - `View` toggles **Agent clipboard write** (default off; each write still asks) and **Desktop notifications** (`notify-send` when no window is attached; unread background turns show `•` and approvals show `!` in the list and window title).
   - Each session row shows private process-tree memory (`RssAnon + RssShmem` in M/G; amber from 1 GiB, red from 2 GiB), and the bottom-left summary reports total session, host, and window memory.

## Agent, script CLI, and loopback HTTP (`lico ...` and `127.0.0.1`)

- **Capabilities, status, settings, SSH hosts, and files**: `lico capabilities`, `lico status`, `lico resources`, `lico ssh hosts`, `lico ssh check HOST`, `lico settings [--clipboard-write on|off] [--notifications on|off] [--group-by account|workspace] [--font-size 12..20] [--show-events on|off] [--show-hidden on|off] [--last-cwd DIR] [--last-view start|files|session] [--last-session ID]`, `lico files [DIR] [--hidden|-a] [--ssh-host HOST]`, `lico files --read FILE [--ssh-host HOST]`, `lico host stop [--force]`.
- **Accounts**: `lico account create --provider codex|claude --label Work [--ssh-host HOST]`, `lico account rename ID LABEL`, `lico account list`, `lico account login ID [--device]`, `lico account auth ID`, `lico account default ID`, `lico account affected ID`, `lico account remove ID detach|end`.
- **Sessions, Call Rooms, chat history, and search**: `lico session list`, `lico chat list [--cwd DIR | --global] [--ssh-host HOST] [--account ID] [--query TEXT] [--recorded] [--offset N] [--limit N]` (each chat carries `turns`, `null` when unknown), `lico chat latest [--cwd DIR] [--ssh-host HOST] [--account ID]` (the latest chat with a saved transcript), `lico session create --kind claude --account ID [--cwd DIR] [--worktree BRANCH] [--mode auto|default] [--resume ID | --resume-latest]` (`--resume-latest` continues the latest chat of `--cwd` for the account, reuses its tab when it is open, or makes a new session and says so; the agent tool `mcp__lico__create` has the same as `resume: true`, default off), `lico session mode ID auto|default`, `lico session send ID TEXT|- [--from ID2 | --conversation --from ID2]`, `lico session watch ID`, `lico session close ID`, `lico session resume ID`, `lico session rebind ID ACCOUNT`, `lico session rename ID [NAME]`, `lico session delete ID`, `lico call list`, `lico call show CALL_ID`, `lico call start --from ID --to ID2 [TEXT]`, `lico call say CALL_ID TEXT`, `lico call hangup CALL_ID`, `lico call close CALL_ID`, `lico history ID BEFORE [LIMIT]`, `lico search QUERY [--session ID]`.
- **Loopback HTTP (`--http-port PORT|auto --http-token-file FILE`)**: Bound strictly to `127.0.0.1` with `Host`/`Origin` validation and `Bearer` credential checks; serves `GET /v1/capabilities`, `POST /v1` (every non-streaming v1 operation), `GET /v1/ssh/hosts`, `POST /v1/ssh/check`, `GET/POST /v1/accounts`, `POST /v1/accounts/<id>/rename`, `GET/POST /v1/sessions`, `GET /v1/sessions/chats`, `GET /v1/sessions/<id>[/snapshot|/events|/history]`, `POST /v1/sessions/<id>[/input|/mode|/rebind]`, `GET/POST /v1/calls`, `GET /v1/calls/<id>`, `POST /v1/calls/<id>[/say|/hangup|/close]`, `GET /v1/search`, `GET /v1/files`, `GET /v1/files/read`, `GET/POST /v1/settings`, `POST /v1/approvals/<id>/response`, and `POST/DELETE /v1/views`.
- **Screen, clipboard, and displays**: `lico capture --screen|--window ID|--region x,y,w,h --out FILE`, `lico clipboard read ...`, `lico clipboard write ...`, `lico display [status|stop|run]`, `lico real-screen stop`.
