## What was built

An agent in a Claude Code session can operate an isolated per-session virtual X11 display (`Xvfb`, `1280x800x24`, `-nolisten tcp`, `-noreset`) without touching the person's desktop, start programs on that display (`lico display --session ID`, `lico display run --session ID -- CMD`), and drive GUI applications (`look`, `click` left/right/middle/double, `move`, `drag`, `type`, `key`, `scroll`, `wait`) through XTEST via the short-lived `lico xjob computer` helper, receiving a shrunk PNG screenshot (`<= 1568 px` on the long side) after every action with exact coordinate scaling. Real-screen control (`target = "real"`) is off by default (`SF-06`) and gated behind a per-session, memory-only 15-minute approval in `lico gui` (`keep` refused) with a crimson top warning bar (`!! REAL SCREEN: '<name>' is controlling this screen   MM:SS left   [ Stop now ]`), global `Ctrl+Alt+Esc` instant stop, `Session` menu administrator controls, and secret-free host audit logging (`SF-03`).

- **S01 & S02 `9bed6ab`: focus measurement without a window manager and per-session virtual displays (`vdisplay/mod.rs`, `memory.rs`, `cli.rs`, `CU-01`, `CU-04`, `CU-08`, `MB-03`, D1, D5, D6, D7).** Enabled `x11rb` `features = ["xtest"]` (already cached in `x11rb-protocol 0.13.2`, zero new crate dependencies; `suite acceptance` clean-clone build passed). `vdisplay` spawns one `Xvfb` (`1280x800x24`, `-nolisten tcp`, `-noreset`, `-displayfd`) per asking session in its own process group (`setsid`) on a lazy `OnceLock` immortal creator thread (`lico-vd-keeper`, D5) so `prctl(PR_SET_PDEATHSIG, SIGKILL)` tracks the host process lifetime rather than short-lived HTTP worker threads. Displays stop automatically after 10 idle minutes (`600 s`, swept on the host maintenance tick), on `session.close`, on `session.purge` and on `host.stop`, and `memory::annotate` sums each virtual display's process group into `status["sessions"][i]["memory"]`. Exposed over socket ops `display.ensure`, `display.status`, `display.stop` and CLI `lico display [--session ID]`, `lico display status`, `lico display stop`, and `lico display run --session ID -- CMD`.
- **S03 `9bed6ab`: short-lived XTEST computer helper and coordinate scaling (`computer/mod.rs`, `computer/xact.rs`, `xjob.rs`, `CU-02`, `CU-03`, `CU-08`, `XF-07`).** Hidden `lico xjob computer` executes `look`, `click` (`left`, `right`, `middle`, `double`), `move`, `drag`, `type`, `key`, `scroll` (`up`, `down`, `left`, `right`, `ticks`) and `wait` (`0..5000 ms`) via `x11rb::protocol::xtest::fake_input`, maps agent coordinates `(x, y)` in `[0, AW - 1] x [0, AH - 1]` to screen coordinates via pixel-centre inverse scaling (`round((x + 0.5) * W / AW - 0.5)`), assigns explicit X11 `SetInputFocus` to the target mapped top-level child window when no window manager owns focus (`CU-08`: `0 MiB` standing WM cost), dynamically allocates temporary keysyms on unused keycodes for arbitrary Unicode text (`type`) before restoring the keymap, and captures the post-action screen via `capture::run` in 256 KiB bands with zero standing X11 connection in `lico-host`.
- **S04 `9bed6ab`: MCP `computer` tool, 15-minute real-screen gate, audit log, and `lico gui` administrator controls (`computer/real.rs`, `screentools/`, `calls.rs`, `mcp.rs`, `gui/realbar.rs`, `gui/menu.rs`, `CU-05`, `CU-06`, `SF-01`, `SF-03`, `SF-05`, `SF-06`, D2, D3).** Added `computer` to the Claude-only MCP tool channel (`LIST_BUDGET = 5120`, compact `tools/list` JSON <= 4,991 bytes). `target = "virtual"` (default) ensures the session's private virtual display without prompting; `target = "real"` returns `{"status": "pending", "approval_id": ...}` immediately when ungranted, opens a non-sticky host approval card in `lico gui` (`keep: true` refused; `Shift+S` hidden), and on `Allow` (`Y`) grants a 15-minute (`900 s`) memory-only window for that session. Every `target = "real"` action writes an audit line (`audit tool=computer target=real session=<id> action=<act>`) without screen contents or typed text (`SF-03`). `gui/realbar.rs` draws the crimson top bar with live MM:SS countdown and `[ Stop now ]` button; `Ctrl+Alt+Esc`, `Session > Stop real-screen control`, and `lico real-screen stop [--session ID]` revoke immediately; `Session > Virtual display: start / stop (:N)` lets the administrator manage virtual displays directly in `lico gui`.

## Security

- **Isolation and consent (`CU-05`, `CU-06`, `SF-01`, `SF-03`, `SF-05`, `SF-06`):** `computer` defaults to the session's private `-nolisten tcp` `Xvfb` virtual display; `target = "real"` is off by default, requires explicit window approval, refuses `keep = true`, expires in 15 minutes (`900 s`), vanishes on host restart (memory-only table), revokes immediately via `[ Stop now ]`, `Ctrl+Alt+Esc`, `Session > Stop real-screen control`, or `lico real-screen stop`, and logs action metadata without screen pixels or typed strings (verified by secret-canary test `SECRET_TYPED_CANARY_8842`). Provider child environments remain strictly isolated (`PATH`, `HOME`, `LANG`, `LC_CTYPE`, `CODEX_HOME` only; `LICO_SOCKET` and `XDG_RUNTIME_DIR` are never leaked into provider processes).
