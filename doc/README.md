# Documentation

The product specification, proposed M01 milestone and draft first phase plan
will be published together on a documentation branch for review. They are not
yet approvals, results or implemented capabilities.

Documentation uses at most five categories: product, milestones, plans, reports
and design. Categories appear when they contain actual material. Milestone,
plan and report files retain their date hierarchy and phase IDs. A date archive
is navigated through indexes with at most five visible entries per page; extra
entries receive continuation pages. Archive growth never adds a sixth product
module or silently moves an existing link.

Public documentation describes the product and contribution contract. Local
operational bindings and private inspection evidence remain outside public source.
