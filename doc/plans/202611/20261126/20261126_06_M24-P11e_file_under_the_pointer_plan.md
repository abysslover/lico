## What this phase gives the person

In a conversation, a **file name that is really there** is a link: with the pointer over it the name is **underlined** and the pointer becomes a hand; a **click** on it opens the file in the window's file viewer (the pane the Directories list opens a file in: text with its lines wrapped, a refusal in words for what it does not show, a file that is not text handed to the system's program as there). A folder is opened in the same viewer as a list. `path:12` (and `path:12:3`) opens the file at line 12.

What counts as a file name (read from the text of the line under the pointer, nothing is sent anywhere):

- an absolute path (`/tmp/x.log`), a path from the home folder (`~/notes.md`), a path from the folder of the session (`./a.rs`, `../b/c.txt`, `src/gui/ui.rs`) and a bare name with an extension (`Cargo.toml`), each possibly with `:LINE` or `:LINE:COLUMN` after it;
- not a web address (`https://...`), not a version or a number (`0.8.2`, `1.5`), not a word that ends a sentence (`e.g.`): the characters around the name (quotes, backticks, brackets, a comma, a full stop at the end) are not part of it;
- **and the thing is there**: it is looked at on the machine (relative to the session's folder) when the pointer is over it, so a name that is not a file is never underlined. The look has 30 ms to answer (a network folder that does not answer in that time is not a link at that moment; the pointer moving again asks again).

What does **not** change: a click elsewhere in a block still selects the whole block and folds it (P11c), a drag still selects and copies, Shift+click still extends the selection; a click on a file name opens the file and does not fold the block.

Not in this phase (the owner's, written in the report): the file opens in the file viewer **of the main pane** (with the same close and back as when a file is clicked in the list on the left), not as a new tab in the bar above it (the bar holds sessions, calls, browser and terminal tabs; a file tab would be a fifth kind with its own state, selection and close, which is a phase of its own); a session on another machine (ssh) has no links (a name there cannot be looked at from here in 30 ms); the Call Room, panels, the browser and the terminal tabs have none.

## Why it is built this way (what was found)

- The conversation is one text buffer; `hit_lines` has one record per laid-out row with the pixel rows and the line it belongs to; the layout's glyphs say, for every character, its bytes in the line's text and its pixel span. So the name under the pointer is found from the last frame's layout with no new measuring, and the underline is drawn from the same glyph spans (a name that wraps has one stretch on each row).
- A hover that changes pixels must be one of the things the scroll step knows about (`scroll::Overlay`): while a link is under the pointer the frame is repainted whole (as for a selection or a menu), so a kept row can never carry the underline of a moment ago. The scroll oracle (the step against a full repaint) is run with a link hovered.
- The click goes where the block click goes (`main_mouse_release`, a stationary unshifted press), **before** it: a name takes the click, the rest of the block keeps it.
- The viewer is the one the sidebar opens (`files_open_sidebar_preview`, `files_open_at`); the host decides what it will show (`folder.read`), so a path the host refuses says so in the viewer's words. What the agent wrote is data: a click opens a read-only view, nothing is run and nothing is sent.
- Looking at a path from the window's thread must not freeze it (a network mount that does not answer): the look runs on a short-lived thread, the window waits 30 ms for the answer at most, the answers are kept for the same name (a small table), and a late answer is used by the next look.
- `ui.rs` is pinned at 1114 lines: the new code lives in `gui/filelink.rs` (the detection, the look, the hover, the click, the underline) and its tests; the lines of `ui.rs`, `clip.rs` and `scroll.rs` that change are joined, not added.

## Decisions

| # | Decision | Detail |
|---|---|---|
| D1 | **What is a name** | the characters between spaces and the marks `" ' \` < > ( ) [ ] { } , ; |` and `*` `=`, a full stop, a colon or an exclamation or question mark at the end taken off, and one to three Korean letters glued to an ASCII letter or digit at its end (`src/main.rs를`); it is a name when it starts with `/`, `~/`, `./` or `../` (with something after it), or its last part has a stem, a dot and an extension of 1 to 8 letters and digits with at least one letter; `:LINE` and `:LINE:COLUMN` after it (numbers that fit 32 bits) are the line; a `://` inside, or only digits and dots, is not |
| D2 | **It must be there** | `std::fs::metadata` of the resolved path (the session's folder for a relative one, `$HOME` for `~/`); a file or a folder (a socket or a pipe is not a link); 30 ms on a short thread; the answers are kept for 5 seconds per resolved path (up to 256), a "did not answer" is not kept, the thread's late answer is taken by the next look, and at most 16 unanswered looks are out at once |
| D3 | **Where** | the transcript rows of a conversation of the workbench window (not a panel, the browser, a terminal, the Call Room, nor a session on another machine); not in the gutter where the time stands |
| D4 | **Hover** | the underline: one pixel row (`scale` px) under the glyphs of the name, in the ink of the text, from the first glyph to the last of each row; the pointer is a hand while it is over a link and the window's own elsewhere |
| D5 | **Click** | a stationary left press and release on a link with no Shift: a file opens in the viewer (at `LINE` when given; **a file that is not text is shown by the viewer as such and never handed to the system's program**), a folder opens the viewer as a list there; the selected line is dropped; a press that moved is a drag; the click looks at the pointer's place itself (no move need come before it) |
| D6 | **The dump** | `links` (new): `armed`, `hover` (the name, its resolved path, `file` or `folder`, the line, the rectangles drawn) or null, and `names` (every name in the rows on the screen, looked at or not: name, line, the rectangle of its first row) |
| D7 | **The scroll step** | a hovered link counts as an overlay: a repaint of the whole text area while it lasts |

## Not decided here (the owner's, written in the report)

- A file tab in the bar (a fifth kind of tab) instead of the viewer in the main pane: later, when the viewer is wanted beside the conversation.
- Links in a session on another machine (the viewer can read remote files, but a name cannot be looked at from here in 30 ms).
- Names with spaces in them (`My Notes.md`) are not found: a space ends a name.
