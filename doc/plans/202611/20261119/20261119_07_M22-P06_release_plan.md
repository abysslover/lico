## What this phase changes

1. **The version**: the host is `0.8.0` (a minor step: the window lost a concept, Global; the browser tab got its bar, its search and its remembered pages; the terminal of M23 P01 to P03b is in the same build). `src/host/hostd/Cargo.toml`, `Cargo.lock`, the README, and the two tests that name the version (`tests/test_control_parity.py`, `tests/test_single_executable.py`).
2. **The guide** (`doc/manual_end_to_end.md`): the browser paragraph says the bar at the top, the empty first page, the search and the setting `browser_search` (how to write it, the default, what a wrong value does), the remembered pages and the two menu entries, and no longer speaks of the ring and the header; the window items say what the window is now (two left tabs, `Home`, the toolbar of four icons, the wizard of New session with its four pictures, the menus as trees, the Chats cards, the pages in Chats, the tabs with no buttons and the `⇄` mark of a room, the bottom rows) and name no button that is gone.
3. **The CHANGELOG** entry `0.8.0` in the style of the others (milestone, report, release commit, highlights, measured, components, tests), and the M22 report.
4. **The measurement**: the whole suite cold (the version of the host is a file that every test depends on, so the change selects everything), `cargo xtask check`, `verify`, `graph`, `system`, and the clean-clone acceptance (two clones build the same bytes; the size).
