## Goal

Give the person running several sessions at once the three everyday-comfort capabilities of M02 across `lico gui` and the `lico` CLI without adding a resident index, a background daemon, or a runtime dependency:
1. **Git worktree sessions (`WT-01`, `WT-02`, `SF-07`):** when a session's chosen folder is a git repository, Lico can create a new git worktree and branch (`--worktree <branch>`, or `[x] start in a new git worktree` + `Branch` on the new-session screen) under `<workspace_root>/worktrees/<session_id>` and start the session inside it. Closing or deleting a session that owns a worktree asks whether to keep or remove the worktree; if the worktree has uncommitted changes (`git status --porcelain`), Lico asks one more confirmation before removal. Removing a worktree never deletes the branch and never touches the repository's own working tree.
2. **Attention marks and desktop notifications (`NT-01`, `NT-02`, `SF-02`, `SF-03`):** when a background session finishes a turn or waits for an approval, its session-list row shows an attention mark (`•` for unread finished, `!` for pending approval) and the X11 window title carries an ASCII suffix hint (`[approval]` or `[finished]`) while keeping the `Lico <version>` prefix intact. Input echo records (`>> ...`) never raise attention. Viewing a session clears its unread mark. Desktop notifications run `notify-send` when it is present on `PATH` (no new dependency), carry only the sanitized session label (never message text, command text, or sign-in codes), and can be switched off and on in `settings.json` via `View > Desktop notifications: on/off` and `lico settings --notifications on|off`.
3. **Conversation search (`SR-01`, `SR-02`):** `Ctrl+F` (`View > Find in conversation`) searches inside the open conversation with next/previous stepping (`Enter` / `Shift+Enter`) and visual row highlighting; `Ctrl+Shift+F` (`View > Search all sessions`, or `Tab` inside the search bar) searches across all non-purged text sessions and jumps directly to the matched line of the chosen session (loading older history around that sequence number when needed). No search index stays resident in `lico-host` or `lico gui`: segment files are scanned on demand and dropped at the end of each query.

## Deviations and refinements

- **D1 (`NT-01` window-title suffix instead of prefix):** `ProductWindow.window_id()` in `src/lico_measure/captures.py` locates the X11 window with `xdotool search --name "^Lico( [0-9]|$)"`. Prefixing the window title (`(!) Lico ...`) would break window discovery across the measurement and test harness. Appending ` [approval]` or ` [finished]` to `ident::title()` satisfies `NT-01` ("and the window title carries a hint"), keeps pure ASCII in `WM_NAME`, and preserves `^Lico( [0-9]|$)` compatibility.
- **D2 (`WT-01`, `WT-02` worktree location and recent-folder memory):** worktrees created by Lico live at `<workspace_root>/worktrees/<session_id>` (separate from scratch folders `<workspace_root>/<session_id>`), while `recent_folders.json` records the parent git repository path (`worktree_repo`) rather than the internal worktree path so the next `Ctrl+N` offers the repository again. Under `SF-07`, socket ops `session.close` and `session.purge` default `worktree` to `"keep"` when omitted so automated callers never delete a worktree implicitly; `lico gui` always asks keep (`K`) vs remove (`R`) when `worktree.exists` is true, and asks a second confirmation (`D` remove anyway / `K` keep / `N` cancel) if `git status --porcelain` reports uncommitted or untracked changes (`worktree_dirty`).
- **D3 (`NT-02` notification privacy and testability):** `notify-send` receives only `--app-name=Lico` and the sanitized session title (`'name' finished` or `'name' needs approval`), never transcript text, approval prompt commands, or credentials (`SF-02`, `SF-03`). `LICO_NOTIFY_BIN` overrides the binary path in tests so both present and missing notification helpers are tested deterministically without touching the desktop bus.
- **D4 (`SR-01`, `SR-02` non-destructive search input and history jump):** opening search (`Ctrl+F` / `Ctrl+Shift+F`) edits `SearchState::query` directly without overwriting `Editor`'s per-session draft. Jumping to a match whose `seq` lies before the 40-line live snapshot loads a bounded history slice around `seq` from disk via `history` and centers `scroll` on `seq`, keeping zero resident index in both host and client.
- **D5 (`TST-01` and `TST-07` budgets):** inline `core.rs` unit tests move to `core/tests.rs` (mounted via `#[path = "core/tests.rs"]` so `testmap.py` maps it to module `core`, shrinking `core.rs` from `1,087` to `988` lines), `refresh_list` moves from `gui/ui.rs` to `gui/attn.rs`, and `ensure_host` / `try_ensure_host` move from `gui/mod.rs` to `gui/update.rs` (keeping `gui/mod.rs` at `744` lines, well below `800`); `tests/test_everyday_comfort.py` shares one `ProductWindow` across its GUI checks so warm `--cold` stays under `180.0 s`.
